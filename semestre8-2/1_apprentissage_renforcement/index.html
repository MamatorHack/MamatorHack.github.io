    Module 9 : Apprentissage par Renforcement (Reinforcement Learning - RL)

    Objectif du cours : Découvrir le troisième grand paradigme de l'apprentissage automatique, où un agent apprend par essais et erreurs en interagissant avec un environnement. Vous maîtriserez les concepts fondamentaux du RL à travers une analogie simple et comprendrez le dilemme exploration/exploitation.

    1. Introduction : Apprendre sans Professeur, par l'Expérience

    Jusqu'ici, nous avons surtout vu l'apprentissage supervisé, où un modèle apprend à partir d'un jeu de données avec des étiquettes (un "professeur" qui donne les bonnes réponses).

    L'apprentissage par renforcement est différent. Il n'y a pas de jeu de données pré-établi. L'agent apprend en agissant dans un environnement et en observant les conséquences de ses actions. C'est le domaine de l'IA qui se rapproche le plus de la manière dont les êtres vivants apprennent.

    L'Analogie du Dressage de Chien

    Dresser un chien est un parfait exemple de RL :

    • L'Agent, c'est le chien.

    • L'Environnement, c'est la pièce, le jardin, et vous (le maître).

    • Les Actions sont ce que le chien peut faire : s'asseoir, aboyer, courir...

    • La Récompense est la friandise que vous lui donnez quand il fait la bonne action.

    • La Politique est la stratégie que le chien apprend : "Quand mon maître dit 'assis', si je m'assois, je reçois une friandise. C'est donc la meilleure action à faire dans cet état."

    2. Les Composants Clés d'un Problème de RL

    Tout problème de RL peut être décrit par ces cinq éléments :

    1. L'Agent : C'est "l'apprenant" ou le "décideur". C'est le programme que nous écrivons (le chien).
    2. L'Environnement : C'est le monde avec lequel l'agent interagit. L'environnement réagit aux actions de l'agent et change d'état (le salon).
    3. L'État (State) : C'est une description de l'environnement à un instant T. (La position du chien, l'ordre que vous donnez).
    4. L'Action (Action) : C'est un choix que l'agent peut faire dans un état donné. (S'asseoir, se coucher).
    5. La Récompense (Reward) : C'est le signal de feedback que l'environnement envoie à l'agent. L'objectif de l'agent est de trouver une stratégie pour maximiser la somme de ses récompenses futures.

    3. Le Dilemme Fondamental : Exploration vs. Exploitation

    C'est le défi central et le plus fascinant du RL. L'agent doit constamment arbitrer entre deux stratégies :

    • Exploitation : Utiliser la meilleure stratégie qu'il connaît déjà.

      • Analogie : Le chien sait que s'asseoir lui rapporte une friandise. Il va donc s'asseoir à chaque fois pour être sûr d'avoir sa récompense.

    • Exploration : Tenter une nouvelle action, au risque de ne pas avoir de récompense, mais dans l'espoir de découvrir une stratégie encore meilleure.

      • Analogie : Et si, au lieu de s'asseoir, il donnait la patte ? Peut-être que cette action lui rapporterait une friandise encore plus grosse ! Il doit essayer pour savoir.

    Un agent qui n'exploite que ce qu'il sait ne s'améliorera jamais. Un agent qui n'explore que de nouvelles options n'utilisera jamais ce qu'il a appris. Le succès en RL vient d'un équilibre intelligent entre les deux.

    4. Les Applications : Au-delà des Jeux

    Le RL a connu son heure de gloire en battant les meilleurs joueurs du monde au jeu de Go (AlphaGo), mais ses applications sont bien plus larges :

    • Robotique : Apprendre à un bras robotique à saisir des objets qu'il n'a jamais vus.
    • Finance : Créer des stratégies de trading automatique.
    • Optimisation : Optimiser le refroidissement des data centers de Google, réduisant la facture d'électricité de 40%.
    • IA Générative : Le "RLHF" (Reinforcement Learning from Human Feedback) est utilisé pour aligner les LLM comme ChatGPT.
