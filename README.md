Ce projet est un site web éducatif conçu pour servir de support d'apprentissage aux étudiants de l'ESAIP, École d'Ingénieurs, qui se préparent à intégrer la nouvelle spécialité en Intelligence Artificielle.

**[➡️ Accéder au site en ligne](https://VOTRE_NOM_UTILISATEUR.github.io )**

---

## 🎯 Objectif du Projet

Ce site est né d'une initiative personnelle avec un double objectif :
1.  **Vulgariser et rendre accessibles** les concepts fondamentaux de l'IA qui seront abordés dans la spécialité.
2.  **Fournir un support de révision complémentaire**, structuré et de haute qualité, pour aider les étudiants (y compris moi-même) à aborder ce nouveau cursus avec les meilleures bases possibles.

Le contenu a été rigoureusement élaboré en s'appuyant sur des sources académiques, des cours de référence et des documentations techniques pour garantir sa fiabilité.

> **Note importante :** Cet outil est un support d'apprentissage informel et ne remplace en aucun cas les cours officiels dispensés par les professeurs de l'ESAIP, qui restent la référence absolue.

## 📚 Contenu Abordé

Le site couvre l'intégralité du programme de la majeure IA, réparti sur trois semestres :

*   **Semestre 7 : Les Fondamentaux**
    *   Éthique et IA
    *   Ingénierie et Analyse de Données
    *   Deep Learning
    *   Optimisation Multicritère

*   **Semestre 8-1 : Domaines d'Application**
    *   IA Explicable (XAI)
    *   Traitement du Langage (TALN)
    *   Vision par Ordinateur
    *   IA Générative

*   **Semestre 8-2 : Sujets Avancés & Projet**
    *   Apprentissage par Renforcement
    *   Green AI
    *   Systèmes d’IA (MLOps)
    *   Challenge IA

## 🚀 Lancer le Site en Local

Si vous souhaitez faire tourner ce projet sur votre propre machine :

1.  **Clonez ou téléchargez ce dépôt.**
2.  **Assurez-vous d'avoir Python installé.**
3.  **Installez les dépendances** via le terminal :
    ```bash
    pip install mkdocs mkdocs-material
    ```
4.  **Lancez le serveur de développement** à la racine du projet :
    ```bash
    mkdocs serve
    ```
5.  Ouvrez votre navigateur à l'adresse `http://127.0.0.1:8000`.
